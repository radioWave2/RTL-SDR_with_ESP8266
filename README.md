# RTL-SDR_with_ESP8266
Streaming raw I/Q data from RTL-SDR over Wi-Fi using ultra-low-cost ESP8266.
Wireless SDR Bridge: Streams I/Q data via ESP8266 AP (192.168.4.1:1234). Hardware RF Probe: Antenna -> 100nF (CH104) -> 1N60 Germanium Diodes (Doubler) -> 100nF -> BC547 Transistor Base. Collector to ESP A0 & 10k Pull-Down to GND. Emitter to 3.3V. 2nd 100nF capacitor grounded.

NOTE: CODE IS MAINLY TURKISH, YOU CAN MODIFY.
